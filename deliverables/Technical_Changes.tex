Bug B & The braking row printed a raw Python exception name; now a plain ``Not available --- reason'' sentence, details in the log.\\
Bug C & The Executive Summary said ``design pass'' for every component; statuses are now derived from the checks (PASS only if every check has data and UR\,$\le$\,1.0). The demo design correctly reports FAIL.\\

\section{Rationale for architectural and styling choices}
\begin{itemize}
\item \textbf{One data layer.} The Executive Summary, Table 5.28 and the Section 5.5 charts read the same \f{report\_data} values, so they cannot disagree.
\item \textbf{A table builder instead of hand-written longtables.} One function gives every table the same head/foot behaviour; a layout fix applies to all tables at once.
\item \textbf{One style source.} Formatting changes in one file instead of eight chapter modules.
\item \textbf{Honest charts.} One unit per chart; missing values are labelled, never drawn as a bar or counted as passing.
\item \textbf{Disclose, don't patch.} Problems in the analysis/design modules are reported in the PDF, not silently changed by the report code.
\end{itemize}

\section{Visual enhancements and open polish}
\textbf{Done:} shaded table headers; pass/fail/no-data bar colours with value labels; failing URs in red; framed ``no results'' chart panel; visible placeholder when a chart cannot be generated; Data Consistency Notes box; unnumbered title page with ``Page X of Y'' equal to the PDF page; no table wider than the page.\\
\textbf{Open polish:} 11 overfull hboxes ($\le$\,5.1\,pt, single words such as ``Diagonal'' in narrow cells) and 2 overfull vboxes (5.4\,pt) remain, because removing them would change column widths; some pages end with white space where a girder group or section is kept together; chapter templates are still large raw-LaTeX strings.

\section{Known limitations}
\begin{itemize}
\item \textbf{Upstream defects disclosed, not fixed:} D-04 (6 design members for a 4-girder bridge), D-05 (cross-bracing spacing 15\,m input vs 3\,m used), D-06 (analysis vs designed section), D-17 (two deflection results disagree), D-18 (IRC 6 braking function fails for 1--2 lanes), D-19 (analysis ignores the vehicle checkboxes).
\item \textbf{End diaphragms:} no end-diaphragm UR results exist for the demo design (Figure 5.4 says why), and their tonnage cannot be computed for cross-bracing frames.
\item \textbf{Values not provided by the pipeline} are printed as ``Not available'' with a reason (braking force, seismic forces); centrifugal force is shown as not applicable because the modelled bridge is straight in plan.
\item \textbf{Verification scope:} one demonstration case, not a real project, was run end to end; the GUI was driven by code with dialogs bypassed, not clicked by hand.
\item \textbf{Scope exception:} \f{boq\_generator.py} outside the report directory was changed for quantity take-off (approved and disclosed above).
\end{itemize}
